# ADR-0001: 기술 기준

- 상태: 채택 (Java 버전은 TIBRV 테스트 후 확정)
- 날짜: 2026-11-05

## 배경

BE와 MCP 서버를 만들기 전에 구조에 영향을 주는 기준을 정합니다. 지원 기간은 2026년 11월에 확인한 값입니다.

## 결정

| 항목 | 결정 |
| ------------ | -------------------------------------------------------- |
| Java | 21 (Eclipse Temurin) |
| Spring Boot | 4.1 |
| 빌드 도구 | Gradle |
| MCP 스택 | Spring AI 2.0, Streamable HTTP |
| Java 패키지 | `com.lgdisplay.mmd` (`.backend`, `.mcp`로 모듈 구분) |

## 근거

**Java 21**

- 체크리스트의 기준 버전입니다.
- Temurin 무료 지원은 17이 최소 2027년 10월, 21이 최소 2029년 12월, 25가 최소 2031년 9월까지입니다.
- 17은 남은 지원 기간이 짧고, 25는 TIBRV 호환 위험이 더 큽니다.

**Spring Boot 4.1**

- 3.5는 무료 지원이 끝났고, 4.0은 2026년 12월에 끝납니다.
- 4.1은 2027년 7월까지 무료로 지원되고 Java 21을 지원합니다.

**Gradle**

- BE 빌드 → OpenAPI 생성 → FE 타입 생성처럼 이어지는 작업과 변경 폴더 기준 빌드에 유리합니다.
- 폐쇄망이면 Gradle 본체와 플러그인도 반입해야 합니다.

**Spring AI 2.0**

- 기본 전송 방식이 체크리스트와 같은 Streamable HTTP입니다.
- Spring Boot 4.1을 지원합니다.
- BE를 OpenAPI 생성 Java 클라이언트로 호출한다는 체크리스트 규칙에 맞습니다.

**`com.lgdisplay.mmd`**

- LG Display 프로젝트이므로 도메인 `lgdisplay.com`을 거꾸로 쓴 이름을 기준으로 합니다.

## 다시 볼 조건

- TIBRV가 Java 21에서 동작하지 않으면 TIBRV 게이트웨이를 별도 프로세스로 분리해 17로 실행하고, BE는 21을 유지합니다. TIBRV의 지원 JDK 목록은 아직 확인하지 못했습니다.
- 팀 표준이 Maven이면 3단계를 시작하기 전에 빌드 도구를 다시 정합니다.
- 기존 사내 프로젝트의 패키지 규칙이 다르면 그 규칙을 따릅니다.
- Spring Boot 4.1 무료 지원이 끝나는 2027년 7월 전에 업그레이드 계획을 세웁니다.
